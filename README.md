# 매거진 피드 스튜디오

웰니스 매거진 톤의 인스타그램 4:5 캐러셀을 브라우저에서 기획하고, 디자인하고, PNG로 내보내는 도구입니다. 설치 없이 웹에서 바로 씁니다.

## 쓰는 법

1. **시안 고르기**: 만들어 둔 시안 묶음에서 하나로 시작하거나, 마음에 드는 장만 골라 지금 작업에 추가합니다.
2. **기획**: 주제, 카테고리, 포맷, 시안 스타일을 고릅니다. "기획 프롬프트 복사"로 받은 문구를 AI에 붙여 넣고, 돌아온 JSON을 넣으면 슬라이드가 만들어집니다. 워드마크와 마무리 문구도 여기서 바꿉니다.
3. **디자인**: 사진을 올려 장마다 배정하고 글을 고칩니다. 글상자와 이름표는 미리보기에서 끌어서 옮기고, 빈 곳을 끌면 사진 위치가 바뀝니다. 아래 "완성도 점검"이 흐린 사진, 긴 줄, 넘친 글, 출처 누락, 심의에 걸릴 표현을 알려 줍니다.
4. **캡션**: 공식대로 만든 초안을 고쳐서 복사합니다.
5. **내보내기**: 한 장씩 PNG로, 또는 전체를 ZIP으로 저장합니다.

본문에서 `**굵게**` 는 굵은 글씨, `==강조==` 는 강조 상자가 됩니다.

## 들어 있는 시안

- 페이스팩 전체 캐러셀 (7장 완성본)
- 시안 A 포토 에디토리얼
- 시안 C 인터뷰 가이드
- 시안 E 단색 타이포 클래식
- 새 시안 1 원안 정리형 (검은 띠 표지, 라임 태그)
- 새 시안 2 A+C 결합형
- 부가 사진 배치 6가지
- 단색 타이포 모던 모노 / 모던 라임

## 지금까지 정한 것

- 레이아웃 문법은 인스타그램 @shellness.kr 을 참고했습니다. 공개된 최근 게시물 12개를 봤고, 그 계정의 로고, 문구, 사진은 쓰지 않습니다.
- 서체는 Pretendard 입니다. 글자 크기, 자간, 줄 간격은 레퍼런스 원본을 픽셀 단위로 재서 맞췄습니다.
- 브랜드 이름은 임시로 "Seoul Beauty Recipe" 를 넣어 두었습니다. 채널 키컬러는 아직 정해지지 않았습니다.
- 부가 사진은 인물 사진 위에 작은 사진을 얹지 않고, 밝은 페이지에 크게 놓습니다.
- 기능성·의약 표현("미백", "치료" 등)은 점검에서 경고합니다.
